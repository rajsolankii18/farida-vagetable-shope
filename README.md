# Farida Vagetable Shop website

A simple static website for Farida Vagetable Shop, based on its supplied Udyam Registration Certificate.

## Hostinger deployment

Import the Git repository in Hostinger and choose **Deploy as static**. The repository root contains `index.html`; no build command or output directory is required.

## Local preview

```powershell
python -m http.server 4180
```

Open `http://127.0.0.1:4180`.

## Content notes

- Public business information comes from `Maa UDYAM.pdf`.
- Owner identity, PAN, banking, financial, employment and social-category information are excluded.
- The website photograph is an AI-generated representative visual, not a documentary photograph of actual premises, staff, vehicles, products, patients or customers.
- Current products, processing formats, availability, pricing and food-safety information must be confirmed directly with the business.
